# Mobile app

Expo React Native contractor directory. See the [root README](../../README.md).

```bash
npm install
export EXPO_PUBLIC_API_BASE_URL='https://your-api.modal.run'
export EXPO_PUBLIC_CONTACT_FORM_URL='https://docs.google.com/forms/d/e/YOUR_FORM_ID/viewform'
npm run android
npm run typecheck
```

Production build: `npm run build:production`

Set `EXPO_PUBLIC_CONTACT_FORM_URL` for the Agent Maruti contact widget (Google Form link).
